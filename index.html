The command loop

Every signal becomes governed work.

A Command carries the outcome, owner, process, policy, approval, AI authority, evidence, cost, and result. This is the operating contract that connects the website to the company.

Private model control

Run AI locally. Govern it centrally.

LM Studio and Ollama expose compatible local model APIs. NerdCommand places a policy-controlled AI Gateway and local node between those runtimes and company actions, so a model never receives unrestricted operational authority.

Company doctrine

Software is the product. Operating capability is the outcome.

NerdCommand is being built as a software-first company. Implementation and managed operations make the software successful; they do not replace the product business.
