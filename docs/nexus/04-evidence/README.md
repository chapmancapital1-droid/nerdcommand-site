# Evidence folder

Drop verification artifacts here for NEXUS gates.

## Naming

```text
T-XXX-short-name.md
T-XXX-api-test-log.txt
T-XXX-screenshot-*.png
```

## Required sections in each evidence note

1. Task ID  
2. Commands run  
3. Result (PASS/FAIL)  
4. Artifacts / paths  
5. Residual risk  

Reality Checker will reject “looks good” without files here.
